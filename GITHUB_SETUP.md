# GitHub setup

1. Create a repository named `seminar-attendance`.
2. Upload `app.py`, `requirements.txt`, `.gitignore`, `.streamlit/secrets.toml.example`, and `README.md`.
3. Do not upload a real `secrets.toml` or GitHub token.
4. Create a fine-grained GitHub Personal Access Token restricted to this repository.
5. Grant repository Contents permission: Read and write.
6. In Streamlit Cloud, add the secrets from `secrets.toml.example`.
7. Deploy `app.py`.
8. Test with a seminar URL.
